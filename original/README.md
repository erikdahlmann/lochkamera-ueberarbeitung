# Projekt Lochkamera

Interaktives Unterrichtsmaterial (Physik, Klasse 8): Schülerinnen und Schüler optimieren eine Lochkamera.

- `index.html` – Startseite
- `lochkamera/` – einfache 2D-Fassung (Stationen 0–6)
- `lochkamera_3d/` – Fassung mit drehbaren 3D-Animationen (iPadOS 15+)

Jede HTML-Datei ist eigenständig und funktioniert auch offline.
