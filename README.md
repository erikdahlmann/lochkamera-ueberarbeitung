# Projekt Lochkamera – überarbeitete Fassung

Überarbeitung der Lernseite „Projekt Lochkamera“ von Thomas Vieth (Physik, Klasse 8):
https://viethtom.github.io/lochkamera/

- `dist/` – fertige Seiten (wie im Original: `index.html`, `lochkamera_3d/`, `lochkamera/`). Jede Datei läuft auch offline.
- `src/` – Quellen. Ein Text pro Station (`body.html`) für die 3D- und die 2D-Fassung.
- `build.py` – baut `dist/` aus `src/`: `python3 build.py`
- `original/` – das Original, unverändert.
- `AENDERUNGEN.md` – alle Änderungen mit Begründung.

Die Speicher-Schlüssel der Schülereingaben sind dieselben wie im Original. Gespeicherte Antworten bleiben erhalten.
